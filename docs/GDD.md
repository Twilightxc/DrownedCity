# Drowned City — Game Design Document

Oct 25, 2026 · @J · ชื่อเกมชั่วคราว

## 1. ภาพรวมและเสาหลัก

**Logline:** เมืองจมน้ำหลังโรคระบาด ผู้เล่นนำชุมชนผู้รอดที่ตั้งฐานบนยอดตึก บริหารคนและทรัพยากรแบบ State of Decay กลางวัน และออกเรือสำรวจหรือป้องกันฐานจากฝูงซอมบี้แบบแอ็กชันในยามค่ำคืน

| หัวข้อ | รายละเอียด |
| --- | --- |
| แนว | Survival management + top-down action (isometric 3D, กล้อง orthographic) |
| มุมกล้อง | Isometric orthographic หมุนได้ 90° ซูมได้ |
| แพลตฟอร์ม | เฟส 1: เดโมเว็บ (GitHub Pages + itch.io) · เฟส 2: PC บน Steam |
| Engine | Godot 4 (GDScript; ส่วนจำลองที่หนักย้ายไป C++ GDExtension ภายหลัง) |
| ความยากหลัก | ตายถาวรเสมอ (permadeath) |
| ผู้เล่นเป้าหมาย | คนที่ชอบ State of Decay, Frostpunk, This War of Mine และ arcade ยิงซอมบี้แบบ Boxhead |
| ความยาวต่อรอบเล่น | หนึ่งชุมชน 10–20 ชั่วโมง เล่นซ้ำได้ด้วยแผนที่ procedural และ legacy |

**เสาหลักการออกแบบ (ใช้ตัดสินทุกฟีเจอร์ ถ้าไม่ตอบอย่างน้อยหนึ่งข้อให้ตัดทิ้ง)**

1. **ทุกคนมีค่า:** ผู้รอดเป็นคนที่มีชื่อ ทักษะ นิสัย และตายจริง การตัดสินใจมีน้ำหนักเพราะเสียแล้วเสียเลย
2. **น้ำคือทุกอย่าง:** น้ำเป็นทั้งถนน กำแพง อันตราย และทรัพยากร ทุกระบบต้องมีความสัมพันธ์กับน้ำ (เรือ ดำน้ำ ระดับน้ำ ปืนฉีดน้ำ ไฟฟ้าช็อต)
3. **เสี่ยงแลกได้:** ออกไกล ออกทีมใหญ่ ส่งเสียงดัง ได้ของมากแต่เสี่ยงมาก ผู้เล่นเลือกระดับความเสี่ยงเองเสมอ
4. **ฐานที่มีชีวิต:** ฐานเป็นที่ที่อยากนั่งดู ผู้รอดใช้ชีวิตเองตามกิจวัตร คล้าย settlement ใน The Division 2
5. **อ่านออกในพริบตา:** แม้ซอมบี้เต็มจอ ผู้เล่นต้องแยกพวก ศัตรู อันตราย และของเก็บได้ทันที

## 2. Core loop เวลา และสภาพอากาศ

หนึ่งวันในเกมแบ่งเป็น 4 ช่วงชัดเจน เวลาเดินเมื่ออยู่นอกฐานหรือกดเร่ง และหยุดได้เสมอในโหมดบริหาร หนึ่งวันเต็มใช้เวลาจริงประมาณ 20–25 นาที (ดูตารางจังหวะเวลาด้านล่าง)

| ช่วง | เวลาในเกม | สิ่งที่ผู้เล่นทำ | ภัยคุกคาม |
| --- | --- | --- | --- |
| เช้า (วางแผน) | 06:00–09:00 | สรุปคืนที่ผ่านมา จัดงาน สั่งสร้าง เลือกทีมออกสำรวจ | ต่ำ |
| กลางวัน (สำรวจ) | 09:00–17:00 | ออกเรือ ค้นของ ดำน้ำ ภารกิจ ค้าขาย | ปานกลาง ซอมบี้เฉื่อย |
| พลบค่ำ (กลับฐาน) | 17:00–20:00 | กลับฐาน เตรียมป้องกัน ซ่อมแนวกั้น | เพิ่มขึ้นเรื่อยๆ |
| กลางคืน (ป้องกัน) | 20:00–06:00 | เฝ้าฐาน คืนฝูงบุก หรือออกภารกิจกลางคืนความเสี่ยงสูงของดี | สูง ซอมบี้ไวและหนาแน่น |

**จังหวะเวลาจริง (ไม่ได้แบ่งครึ่งต่อครึ่ง):** เวลาในเกมไหลด้วยความเร็วต่างกันตามช่วง กลางวันได้เวลาเล่นมากที่สุดเพราะเป็นช่วงตัดสินใจ กลางคืนสั้นแต่เข้มข้น หนึ่งวันเฉลี่ย 20–25 นาทีจริง

| ช่วง | ชั่วโมงในเกม | เวลาจริง | การไหลของเวลา |
| --- | --- | --- | --- |
| เช้า | 3 | 1 นาที + เวลาวางแผนไม่จำกัด | หยุดระหว่างเปิดหน้าจัดการฐาน |
| กลางวัน | 8 | 12 นาที (1 ชม.เกม = 90 วินาที) | ไหลต่อเนื่อง หยุดได้ |
| พลบค่ำ | 3 | 3 นาที | ไหลต่อเนื่อง มีเสียงเตือนให้กลับฐาน |
| กลางคืน · ฝูงบุก | 10 | 6–10 นาที | เป็นระลอก จบเมื่อเคลียร์แล้วเร่งไปรุ่งเช้า |
| กลางคืน · ปกติ | 10 | 30–60 วินาที | นอนข้าม: เร่งเวลาในโหมด Observer เห็นคนเฝ้ายามและเหตุการณ์เล็กๆ |
| กลางคืน · ออกภารกิจ | 10 | 8–10 นาที | ไหลเหมือนกลางวัน เสี่ยงสูง ของดี |

ทุกค่าอยู่ในไฟล์ data แก้ได้จาก telemetry เช่นถ้าผู้เล่นกลับฐานไม่ทันบ่อย ก็ยืดกลางวัน

**สภาพอากาศ** เปลี่ยนทุกวันตามฤดู และมีผลต่อการตัดสินใจ ไม่ใช่แค่บรรยากาศ พยากรณ์อากาศดูล่วงหน้าได้ 1–3 วันเมื่อมีห้องวิทยุ

| สภาพ | ผลดี | ผลเสีย | พฤติกรรมตัวละคร |
| --- | --- | --- | --- |
| ฝน | กลบเสียง ระยะที่ซอมบี้ได้ยินลดลง เก็บน้ำฝนเข้าถัง | เปียก = เสี่ยงป่วย (ถ้าไม่ใส่ชุดกันฝน) ต้นไม้ไฟไม่ติด | ใส่เสื้อกันฝนเองถ้ามี เข้าหลบใต้เพิง |
| หมอก | ซอมบี้มองไม่เห็นไกล เหมาะกับการย่อง | ผู้เล่นมองไม่เห็นไกล เรือหลงทางได้ | เดินชิดกันเป็นกลุ่ม |
| ร้อนจัด | น้ำลด เปิดทางใหม่บางจุด โซลาร์ผลิตไฟเต็มที่ | หิวน้ำเร็ว สแตมินาฟื้นช้า ผักเหี่ยวถ้าไม่รดน้ำ | หาที่ร่ม เข้าตึก ดื่มน้ำบ่อยขึ้น |
| พายุ | ซอมบี้ออกน้อย ฝนเติมถังเต็ม | ออกเรือไม่ได้ สิ่งก่อสร้างเสียหาย คนบนหลังคาเสี่ยงบาดเจ็บ | ทุกคนหลบเข้าห้องในตึก |
| คืนเดือนมืด | การย่องง่ายที่สุด | ต้องใช้ไฟฉายซึ่งดึงดูดซอมบี้ | ใช้ไฟฉายเท่าที่จำเป็น |

สภาพอากาศทำงานผ่านตัวคูณไม่กี่ตัวใน SimCore: `noise_radius`, `vision_range`, `thirst_rate`, `stamina_regen`, `sickness_chance`, `boat_allowed` ทำให้เพิ่มสภาพใหม่ได้ง่ายโดยไม่ต้องแก้ระบบอื่น

ผลของแต่ละช่วงส่งต่อไปช่วงถัดไป: ทีมที่เลือกตอนเช้ากำหนดของที่ได้ เสียงฐานกำหนดคืนฝูงบุก และผลคืนนั้นกำหนดทรัพยากรและคนที่เหลือในเช้าถัดไป

## 3. ผู้รอดและชุมชน

ผู้รอดทุกคนเป็นทั้งตัวละครที่เล่นได้และแรงงานของฐาน เริ่มต้นด้วย 3 คน ชุมชนเต็มที่ 8–12 คน (เดโมเว็บจำกัดที่ 6)

**ทักษะหลัก** (ระดับ 0–7 เพิ่มจากการใช้จริงและกิจวัตรในฐาน)

| ทักษะ | ผล | เพิ่มจาก |
| --- | --- | --- |
| ฟิตเนส | สแตมินา วิ่ง ว่ายน้ำ พายเรือ แบกของ | วิ่ง พาย ออกกำลังกายที่มุมฟิตเนส |
| ต่อสู้ระยะประชิด | ดาเมจอาวุธระยะประชิด การหลบหลีก | ต่อสู้จริง ซ้อมกับกระสอบทราย |
| ยิงปืน | ความแม่นยำ แรงถีบ ความเร็วเปลี่ยนแม็ก | ยิงจริง เฝ้าหอคอยยิงซอมบี้ |
| ไหวพริบ (Wits) | ค้นของเร็ว เดินเงียบ เห็นกับดัก | ค้นของ อ่านหนังสือ |
| ดำน้ำ | เวลาอยู่ใต้น้ำ ความเร็วใต้น้ำ การมองในน้ำขุ่น | ดำน้ำจริง |

**ทักษะเฉพาะ** (คนละ 1 อย่าง ปลดล็อกห้องหรือการผลิตระดับสูง): แพทย์ · ช่างกล · ช่างไฟฟ้า · เกษตร · เคมี (ระเบิด เชื้อเพลิงปืนพ่นไฟ) · ช่างปืน · ช่างตัดเย็บ · วิทยุสื่อสาร · นักดำน้ำมืออาชีพ · ชาวประมง · ครู (สอนทักษะเร็วขึ้น) · พ่อครัว

**Trait** (คนละ 2–3 อย่าง สุ่มตอนเกิด บังคับมีข้อลบอย่างน้อย 1) ต่างจากทักษะตรงที่ไม่โตจากการใช้ ยกเว้นกลุ่ม "ได้มาระหว่างเกม" ซึ่งเกิดจากเหตุการณ์และสร้างเรื่องราวให้ตัวละคร (เสาหลักที่ 1)

- **ข้อมูล:** trait หนึ่งข้อ = ไฟล์ `.tres` ใน `data/traits/` มีรายการ modifier (`stat`, `weapon_class` ถ้ามี, `mul` หรือ `add`) · น้ำหนักต่อกิจกรรมของ utility AI · รายชื่อ trait ที่ขัดกัน (เช่น Athlete กับ Asthmatic)
- **ผลกับอาวุธ:** modifier ระบุ `weapon_class` ได้ เช่น Steady Hands ลด spread เฉพาะปืนพก ไรเฟิล และปืนซุ่มยิง (โครงสร้างค่าอาวุธอยู่ในหัวข้อ 6)
- เดโมใช้ 12 ข้อ ค่าทั้งหมดเป็นค่าเริ่มต้นสำหรับปรับสมดุล

| กลุ่ม | Trait | ผล |
| --- | --- | --- |
| ต่อสู้ | Steady Hands | spread −20% (ปืนพก ไรเฟิล ซุ่มยิง) |
| | Trigger Happy | RPM +10% แต่ spread +15% |
| | Gun Nut | รีโหลด −20% ปืนสึกช้าลง 25% |
| | Brawler | ดาเมจระยะประชิด +25% |
| | Strong Back | แรงถีบ −15% (LMG ลูกซอง) แบกของสองมือช้าลงแค่ครึ่งเดียว |
| | Panicky ➖ | มีซอมบี้ ≥ 5 ตัวในระยะ 5 m → spread +30% |
| | Pacifist ➖ | ไม่ยิงคน ถ้าถูกสั่งให้ยิงขวัญลด |
| ร่างกาย | Athlete | สแตมินา +20% |
| | Iron Stomach | ไม่ป่วยจากน้ำสกปรกหรืออาหารเน่า |
| | Big Eater ➖ | อาหาร ×1.5 |
| | Asthmatic ➖ | สแตมินาฟื้นช้า โดนแก๊สแรง ×2 |
| | Weak Immune ➖ | โอกาสป่วย ×2 |
| | Light Sleeper ➖ | ความล้าหายช้าลงเมื่อฐานมีเสียง |
| น้ำ | Strong Swimmer | ว่ายน้ำเร็ว +30% |
| | Born Diver | อากาศใต้น้ำ +40% |
| | Hydrophobic ➖ | ดำน้ำไม่ได้ ขวัญลดเมื่ออยู่บนเรือตอนพายุ |
| เสียงและการรับรู้ | Light Footed | รัศมีเสียงเดิน −30% |
| | Eagle Eye | มองไกลในหมอก |
| | Clumsy ➖ | เสียง +30% ค้นของมีโอกาสทำของตก |
| | Snorer ➖ | เสียงฐานกลางคืนเพิ่ม |
| ใจและสังคม | Optimist / Grumpy ➖ | ขวัญชุมชน + / − |
| | Inspiring | เพื่อนในทีม spread −5% ขวัญ + |
| | Loner | ทำงานคนเดียวเร็วขึ้น ออกทีม 3 คนขวัญลด |
| | Night Owl | ผลเสียตอนกลางคืนเหลือครึ่ง กลางวันล้าเร็วขึ้น |
| ภูมิหลัง | Ex-Soldier · Fisherman · Nurse · Mechanic | ทักษะเริ่มต้นสูง (เช่นอดีตทหาร ยิงปืนเริ่มที่ 3) + โบนัสเฉพาะ (ชาวประมง: เรือประหยัดน้ำมัน) |
| ได้มาระหว่างเกม | Hardened | ผ่านคืนฝูงบุก 5 ครั้ง → ลบ Panicky และติดไม่ได้อีก |
| | Survivor's Guilt ➖ | คนสนิทตาย → ขวัญส่วนตัวลด 5 วัน |
| | Water Rat | ดำน้ำครบ 20 ครั้ง → ได้ Born Diver |

**สถานะร่างกายและจิตใจ**

- **สแตมินา / ความล้า:** ความล้าสะสมทั้งวัน ลดสแตมินาสูงสุด หายด้วยการนอนที่เตียง
- **หิว / กระหาย:** ต่ำเกินไปลดสแตมินา นานเกินไปเสียเลือด
- **บาดเจ็บ:** เบา / หนัก (กระดูกหัก แผลเปิด ไฟไหม้) หนักต้องพักห้องพยาบาลหลายวัน
- **ป่วย:** จากฝน น้ำสกปรก อาหารเน่า ติดต่อกันในฐานได้
- **ติดเชื้อ:** จากการโดนกัดหรืออยู่ในโซนสปอร์โดยไม่มีหน้ากาก มีเวลา 3 วันหายาต้านไวรัส ถ้าไม่ทันต้องเลือก: ขับไล่ กักตัว หรือจบชีวิต
- **ขวัญส่วนตัว:** ต่ำมาก → ปฏิเสธงาน ทะเลาะ หนีออกจากฐาน

**รูปลักษณ์ (จำแต่ละคนได้ด้วยตา):** ทุกคนหน้าตาไม่ซ้ำกัน เพื่อให้ผู้เล่นผูกพันกับคนแต่ละคน (เสาหลักที่ 1)

- **เพศและรูปร่าง:** ชาย / หญิง × โครงร่าง (ผอม · ปกติ · ล่ำ · ท้วม) ชายโดยเฉลี่ยสูงและไหล่กว้างกว่าหญิง ส่วนสูงสุ่มในช่วงตามเพศ
- **สีผิว:** palette 6–8 โทน ใช้ร่วมกับศัตรูมนุษย์
- **ผมและหนวดเครา:** ประมาณ 8–10 ทรงต่อเพศ (สั้น ยาว มัด เกรียน โล้น) + สีผม ผู้สูงอายุมีผมหงอก ผมถูกซ่อนเมื่อสวมหมวกในช่องศีรษะ
- **เก็บใน SimCore:** ค่ารูปลักษณ์ + seed ของแต่ละคนอยู่ใน save หน้าตาคงเดิมตลอดเกม
- **เป็นหน้าตาเท่านั้น:** เพศและรูปร่างไม่มีผลต่อค่าความสามารถ (ทักษะและ trait ทำหน้าที่นั้น)

**ตายถาวร:** เมื่อใครตาย ของที่ติดตัวอยู่ตรงจุดที่ตาย (กลับไปเก็บได้) ทุกคนที่สนิทกันได้รับผลด้านขวัญ และมีป้ายอนุสรณ์บนหลังคาฐานถาวร

**สถานะในชุมชน:** คนแปลกหน้า → สมาชิก → พลเมืองดีเด่น → ผู้นำ คนแปลกหน้าควบคุมไม่ได้และอาจขโมยของ ผู้นำกำหนดเป้าหมายใหญ่ (หัวข้อ 12)

**ความสัมพันธ์:** คนที่ทำงานหรือออกสำรวจด้วยกันบ่อยจะสนิทกัน ได้โบนัสเมื่อออกทีมด้วยกัน คู่ที่เกลียดกันทะเลาะกันได้ (เฟส 1.0)

## 4. ฐานบนยอดตึก

ฐานเริ่มจากหลังคาตึกเดียว มีช่องใหญ่ 2 ช่องและช่องเล็ก 4 ช่อง และได้ช่องเพิ่มทุกครั้งที่ยึดชั้นล่างคืนมาได้ ทุกห้องมี 3 tier แต่ละ tier **เปลี่ยนหน้าตาในโลกจริง** และมี animation ตอนทำงาน

| ห้อง | ขนาด | Tier 1 → 2 → 3 (หน้าตา) | เลือกผลิต | ต้องมีทักษะ |
| --- | --- | --- | --- | --- |
| เกษตร | ใหญ่ | กระบะดิน → เรือนกระจก → ไฮโดรโฟนิกส์ | อาหาร / สมุนไพร (ยา) | เกษตร (tier 3) |
| น้ำ | เล็ก | ถังรองน้ำฝน → เครื่องกรอง → ปั๊มกรองน้ำท่วม | น้ำดื่ม / น้ำรดผัก | — |
| พยาบาล | ใหญ่ | เตียงพยาบาล → ห้องพยาบาล → ห้องแล็บ | รักษา / ยาต้านไวรัส | แพทย์ (tier 2+) |
| โรงงาน | ใหญ่ | โต๊ะช่าง → เวิร์กช็อป → โรงงานเครื่องจักร | ซ่อมอาวุธ / อัปเกรดเรือ / อุปกรณ์ติดตั้ง | ช่างกล (tier 2+) |
| คลังอาวุธ | เล็ก | ตู้เก็บปืน → โต๊ะบรรจุกระสุน → สนามยิงซ้อม | กระสุนแต่ละชนิด | ช่างปืน (tier 2+) |
| ห้องเคมี | เล็ก | โต๊ะผสม → ห้องเคมี | ระเบิดทุกชนิด / เชื้อเพลิงปืนพ่นไฟ | เคมี |
| ตัดเย็บ | เล็ก | จักรเย็บผ้า → ห้องตัดเย็บ | ซ่อมชุด / ชุดใหม่ / ย้อมสี | ช่างตัดเย็บ |
| พลังงาน | เล็ก | เครื่องปั่นไฟ → โซลาร์ + แบต → กังหันลม | ไฟฟ้า (ใช้น้ำมันหรือไม่) | ช่างไฟฟ้า (tier 3) |
| ครัว | เล็ก | กองไฟ → เตา → ครัวกลาง | อาหารปรุงสุก (ขวัญ +) / อาหารแห้ง | พ่อครัว (tier 3) |
| ที่นอน | ใหญ่ | เต็นท์ → เตียงสนาม → ห้องพัก | — | — |
| หอเฝ้าระวัง | เล็ก | กระสอบทราย → หอคอยไม้ → ป้อมเหล็ก + สปอตไลท์ | — (ติดตั้งปืนได้) | — |
| วิทยุ | เล็ก | เสาอากาศ → สถานีวิทยุ | สแกนหาเป้าหมาย / พยากรณ์อากาศ / ติดต่อ enclave | วิทยุ (tier 2) |
| นันทนาการ | เล็ก | มุมหนังสือ · มุมฟิตเนส · เป้าซ้อมต่อสู้ | — (ฝึกทักษะ) | — |
| ท่าเรือ | เล็ก (ระดับน้ำ) | ท่าถังลอย → ท่าไม้ + รอกดึง → อู่เรือ | ซ่อมและจอดเรือเพิ่ม | — |

**การเลือกผลิต:** ห้องที่ผลิตได้มีคิวงาน 1–3 ช่อง ใช้เวลา วัตถุดิบ ไฟฟ้า และคนทำงาน ถ้าไม่มีคนในห้อง งานหยุด

**ขยายลงชั้นล่าง (จุดขายหลัก):** แต่ละชั้นต้องทำ 3 ขั้น — กวาดล้างซอมบี้ → สูบน้ำออก (ใช้ไฟและเวลา) → ปิดทางเข้า ได้ช่องเพิ่ม 2–3 ช่อง แต่มีทางเข้าที่ต้องป้องกันเพิ่ม ชั้นที่ได้มาช่วงน้ำต่ำ (ฤดูน้ำลดและฤดูร้อน) จะท่วมกลับเมื่อน้ำขึ้นในฤดูฝน (หัวข้อ 10) ถ้าจะเก็บไว้ต้องเลือกอย่างใดอย่างหนึ่ง:

- **เดินเครื่องสูบตลอดฤดูฝน:** ใช้ไฟหรือน้ำมันทุกวัน เครื่องเสียหรือไฟดับ = น้ำเข้าภายในไม่กี่ชั่วโมง
- **ปิดหน้าต่างและช่องเปิดถาวร:** ใช้วัสดุมากครั้งเดียว ไม่มีค่าใช้จ่ายรายวัน แต่ชั้นนั้นมืด (ต้องใช้ไฟ) และทางเข้าออกเหลือแค่บันได ทั้งสองแบบมีความทนทาน คืนฝูงบุกหรือพายุทำให้รั่วได้

### ต่อเติมอาคาร

ฐานสร้างบน **build grid 1 m** ชุดเดียวกับ NavGrid ทุกชิ้นที่สร้างจึงเปลี่ยนทางเดินของซอมบี้และแนวกระสุนทันที

| ชิ้นส่วน | ใช้ทำอะไร | จุดอ่อน |
| --- | --- | --- |
| แนวกั้น ผนังไม้ / เหล็ก | กั้นทางเข้า สร้างจุดรับฝูง | มี HP พังได้ (ระบบทำลายระดับ 1 หัวข้อ 10) |
| บันได ทางลาด | เชื่อมชั้นและหลังคาต่างระดับ | ซอมบี้ใช้ได้เหมือนกัน |
| **สะพานข้ามตึก** | เชื่อมหลังคาข้างเคียง ยึดตึกใหม่เป็นส่วนหนึ่งของฐานโดยไม่ต้องใช้เรือ | เป็นทางบุกใหม่ของฝูง ตัดหรือยกเก็บได้ |
| เพิงไม้ซ้อนชั้น | ห้องเล็กเพิ่มบนหลังคา | ไฟลามได้ พายุทำเสียหาย |
| ท่าเรือ แพลอย | จอดเรือ ขยายพื้นที่บนน้ำ | ระดับน้ำเปลี่ยนต้องปรับ |

สะพานข้ามตึกคือจุดเด่น: ฐานโตออกด้านข้างได้ แต่ทุกสะพานคือทางเข้าที่ต้องป้องกันเพิ่ม (เสาหลักที่ 3) ชิ้นส่วนทั้งหมดสร้างจาก kit ใน `tools/blender` และมีสภาพ ดี → เสียหาย → พัง เดโมมีแนวกั้นและสะพาน 1 แบบ ส่วนที่เหลือรอ Early Access

### ชีวิตประจำวันของผู้รอด (บรรยากาศแบบ settlement ใน The Division 2)

ผู้รอดที่ไม่ได้อยู่ในการควบคุมใช้ **utility AI**: ทุกกิจกรรมมีคะแนน = ความต้องการของตัวเอง × ความต้องการของฐาน × นิสัย แล้วเลือกทำสิ่งที่คะแนนสูงสุดเอง

| กิจกรรม | ที่ไหน | ผล |
| --- | --- | --- |
| อ่านหนังสือ | มุมหนังสือ | Wits + / เรียนทักษะเฉพาะจากหนังสือที่เก็บมา |
| ออกกำลังกาย | มุมฟิตเนส | ฟิตเนส + / สแตมินาสูงสุด + |
| เฝ้าหอคอย ยิงซอมบี้ที่เพ่นเข้ามา | หอเฝ้าระวัง | ยิงปืน + / ใช้กระสุน / ส่งเสียง |
| ทำงานในห้องตามทักษะ | ห้องที่มีคิว | ผลิตตามคิว ทักษะเฉพาะ + |
| นอน / พักฟื้น | ที่นอน / พยาบาล | ความล้า − / บาดเจ็บหาย |
| กินข้าว รวมกลุ่มรอบกองไฟ | ครัว / กองไฟ | ขวัญ + / ความสัมพันธ์ + |
| ซ่อมแนวกั้น / ห้องที่เสียหาย | จุดที่เสีย | ใช้วัสดุ คืนความทนทาน |
| ตากผ้า รดน้ำผัก ล้างของ | ทั่วฐาน | งานเล็กๆ ที่ทำให้ฐานดูมีชีวิต |
| หลบฝน / หลบแดด | ใต้เพิง ในตึก | ตามสภาพอากาศ |

**โหมดนั่งดูฐาน (Observer):** กดปุ่มเดียวซ่อน HUD กล้องค่อยๆ เลื่อนตามกิจกรรมที่น่าสนใจ (คนทำงาน ซอมบี้เข้าใกล้ คนกินข้าวด้วยกัน) คลิกที่ตัวละครเพื่อดูบันทึกสั้นๆ เช่น "กำลังอ่านคู่มือซ่อมเครื่องยนต์ 3/5" ใช้ได้เป็นโหมดตั้งทิ้งไว้ (idle) หรือสตรีม

## 5. การออกสำรวจและการควบคุมทีม

ผู้เล่นควบคุมคนนำ 1 คนแบบ twin-stick (WASD + เมาส์เล็ง) และพาเพื่อนได้ 0–2 คน สลับตัวควบคุมได้ทันทีด้วยปุ่ม 1/2/3 คนที่ไม่ได้ควบคุมใช้ AI ตามคำสั่งทีม

| ขนาดทีม | ข้อดี | ข้อเสีย |
| --- | --- | --- |
| เดี่ยว | เงียบที่สุด เรือเล็กพอ ฐานมีคนทำงานมาก เสียคนได้สูงสุด 1 | ถูกล้อมง่าย ไม่มีคนช่วยดึงตอนถูกกดทับ ขนของได้น้อย |
| 2 คน | มีคนช่วยยิง ช่วยพยุง เป้เพิ่ม | เสียงดังขึ้น ฐานเหลือคนทำงานน้อยลง |
| 3 คน | กำลังยิงสูงสุด ขนของได้มากที่สุด | ดึงดูดฝูงเร็ว ต้องใช้เรือใหญ่ ถ้าพลาดอาจเสียหลายคนพร้อมกัน ฐานเปราะบางคืนนั้น |

**คำสั่งทีม (กดค้างเปิดวงล้อ):** ตามมา · อยู่ตรงนี้ / คุ้มกันจุด · ยิงเป้าหมายนี้ · ห้ามยิง (เงียบ) · ค้นห้องนี้ · กลับเรือ

**การค้นของ:** ตึกแต่ละหลังมีห้องและตู้เก็บของ ค้นเร็ว (เสียงดัง) หรือค้นเงียบ (ช้า) ตู้บางใบต้องใช้เครื่องมือ (ชะแลง ไขควง สถานะช่างกล) หน้าต่างแผนที่แสดงตึกที่ค้นหมดแล้ว

### สำรวจในอาคาร

ข้อเสนอ 2026-10-27 ทดสอบความเสี่ยงทางเทคนิคใน spike 0.8 ก่อนเฟส 1 (J) ทุกตึกที่เข้าได้มีภายในจริงหลายชั้น การสำรวจคือการไล่ลงจากหลังคาหรือเข้าทางหน้าต่างทีละชั้น

- **กล้องตัดฉาก (cutaway):** เมื่อเข้าไปในตึก ชั้นที่อยู่เหนือตัวละครและหลังคาจะซ่อน ผนังด้านที่หันเข้ากล้องตัดเหลือสูงระดับเอว (ระนาบตัดเป็น uniform เดียวใน shader ผนัง) มุม isometric และการหมุน 90° ใช้ได้เหมือนข้างนอก
- **ทางเข้า:** ประตูหลังคา บันไดหนีไฟ หน้าต่างระดับน้ำ (เอาเรือเทียบหน้าต่าง) หรือระเบิดผนังที่เป็นจุดอ่อน แต่ละทางมีเสียงและความเสี่ยงต่างกัน
- **ภายใน:** สร้างแบบ procedural จาก seed ตามชนิดตึกและย่าน (ห้องชุด ทางเดิน โถงบันได ร้าน สำนักงาน) จาก modular kit เดียวกับภายนอก ห้องที่ยังไม่เห็นมืดจนกว่าจะมีแนวสายตา (ใช้ line of sight ของ NavGrid) ภายในมืดเป็นค่าเริ่มต้น ไฟฉายช่วยได้แต่ตอนกลางคืนดึงดูดซอมบี้
- **ซอมบี้ในตึก:** อยู่เป็นกลุ่มเฉื่อยในห้อง ตื่นตามเสียง ประตูปิดกั้นได้ชั่วคราว ตึกที่เป็นรัง (หัวข้อ 10) มีสปอร์ต้องใส่หน้ากาก
- **ชั้นจมน้ำ:** ใช้กติกาดำน้ำ (ด้านล่าง) ช่วงน้ำต่ำ (ฤดูน้ำลดและฤดูร้อน) น้ำลด 1 ชั้น ชั้นนั้นกลายเป็นชั้นเดินได้ มีโคลน เศษซาก และของที่ยังไม่มีใครค้น
- **เทคนิค:** โหลดภายในเฉพาะตึกที่อยู่ เปิดแค่ชั้นปัจจุบัน ชั้นอื่นซ่อน NavGrid และ flow field แยกต่อชั้น บันไดเชื่อม cell ระหว่างชั้น ซอมบี้ชั้นอื่นจำลองแบบหยาบ เพื่อให้อยู่ในงบ draw call
- **ระบบเดียวกับฐาน:** ชั้นที่ยึดคืนใต้ฐานก็คือภายในตึกแบบเดียวกัน (กวาดล้าง → สูบน้ำ → ปิดทาง หัวข้อ 4)

**ความจุเป้:** เป้มีช่องเก็บจำกัด (เป้เล็ก 4 / เป้ทหาร 8 / เป้เดินป่า 12) ทรัพยากรใหญ่ (ถุงวัสดุ ลังอาหาร) ต้องถือด้วยมือสองข้าง ยิงไม่ได้ เดินช้าลง ต้องขนไปที่เรือ นี่คือจุดที่ทีมหลายคนได้เปรียบ

**ดำน้ำลงชั้นน้ำท่วม:** ต้องใส่ชุดดำน้ำ มีเกจอากาศ ทัศนวิสัยต่ำมาก (ไฟฉายหัวหมวก) ใช้ได้เฉพาะปืนยิงใต้น้ำและมีด เพื่อนบนเรือถือเชือกนำทาง มีของหายากมากสุดในเกม (ยา ชิ้นส่วนเครื่องยนต์ ตู้เซฟ)

**เมื่อถูกกดทับ (downed):** มี 10 วินาทีให้เพื่อนมาช่วย ไม่มีเพื่อน = ตาย ถ้าคนนำตาย การควบคุมย้ายไปคนถัดไปในทีม ถ้าทั้งทีมตาย การควบคุมกลับไปที่ฐาน

**เสียงเป็นทรัพยากร:** ทุกการกระทำมีรัศมีเสียง (เดิน 2 m · วิ่ง 6 m · ปืนพก 25 m · ลูกซอง 40 m · เครื่องเรือ 30 m ค่าเบื้องต้น ปรับได้) ฝนลดรัศมีลง หน้าจอแสดงวงเสียงให้เห็นชัด

## 6. อาวุธและการต่อสู้

ทุกอาวุธมีค่าหลัก: **ดาเมจ · การเจาะ (penetration) · เสียง · ความทนทาน** การเจาะมีสองส่วน คือจำนวนร่างที่กระสุนทะลุผ่านได้ และระดับเจาะเกราะ/ที่กำบัง

### โครงสร้างค่าอาวุธ

อาวุธหนึ่งชิ้น = ไฟล์ `.tres` ใน `data/weapons/` ปรับสดได้จากแผง F4

```
class, caliber, damage, pellets, rpm, mag, reload_s, spread, recoil, range_m, falloff,
stagger, body_pen, armor_pen (L/M/H), noise_m, weight, durability_wear, jam_curve,
waterproof, attachment_slots[], special
```

- **stagger (แรงปะทะ):** ศัตรูชะงักนานเท่าไหร่ต่อนัด (ซ้อนกับการช้าลงเมื่อโดนยิงด้านล่าง)
- **body_pen:** จำนวนร่างที่ทะลุได้ (ใช้ `max_hits` ของ hitscan) ทุกร่างที่ทะลุลดดาเมจนัดนั้นลง 20%
- **armor_pen เทียบกับเกราะ / ที่กำบัง:** ต่ำกว่า = ดาเมจ ×0.25 และไม่ทะลุ · เท่ากัน = ×0.75 · สูงกว่า = ×1 ที่กำบังใช้ตารางเดียวกัน: ไม้ = L · อิฐ กระสอบทราย = M · คอนกรีต = ทะลุไม่ได้
- **weight:** รวมกับเกราะเป็นน้ำหนักตัว ซึ่งกำหนดความเร็วว่ายน้ำและการจม (หัวข้อ 7)
- **jam_curve:** โอกาสติดขัดตามความทนทาน (กฎทั่วไปในการซ่อมบำรุงด้านล่าง) อาวุธบางชิ้นมีเส้นของตัวเองเป็นความสามารถพิเศษ
- **trait:** แก้ค่าเหล่านี้ตาม `weapon_class` (หัวข้อ 3)

**ชื่ออาวุธ:** ใช้ชื่อกึ่งสมมติที่อ้างอิงแบบปืนจริง ไม่ใช้ชื่อแบรนด์หรือเครื่องหมายการค้า (Colt, Kalashnikov, AK-47) ตัวอย่างในตารางใช้ชื่อแบบปืนเพื่อสื่อสารเท่านั้น ชื่อในเกมตั้งตอนทำ content

### ระเบิด (ขว้างได้ และใช้เป็นหัวกระสุนปืนครกได้ทุกชนิด)

ระเบิดขว้าง ลูก 40mm ของ grenade launcher และลูกปืนครกใช้ **ข้อมูลหัวรบ (payload) ชุดเดียวกัน** ใน `data/payloads/` ต่างกันแค่ตัวคูณของตัวยิง (ปืนครก: รัศมี ×1.5) หัวรบใหม่หนึ่งชนิดจึงใช้ได้ทันทีทั้ง 3 ทาง ค่าเริ่มต้นของระเบิดแรงระเบิด: ดาเมจ 150 ที่ศูนย์กลาง รัศมี 5 m ลดลงตามระยะ

| ระเบิดไฟ (molotov) | พื้นที่ไฟไหม้ 8 วินาที ไม่ได้ผลบนน้ำ | กั้นทางเดิน บนหลังคา |

### การซ่อมบำรุง

- อาวุธทุกชิ้นมีความทนทาน 0–100% ต่ำกว่า 50% เริ่มติดขัด ต่ำกว่า 20% ความแม่นยำลดมาก
- **น้ำทำให้สึกเร็ว:** ดำน้ำหรือตกน้ำกับปืนที่ไม่กันน้ำลดความทนทานทันที ฝนลดช้าๆ
- ซ่อมที่โรงงานด้วยวัสดุ หรือซ่อมกลางทางด้วยชุดซ่อม (คืนได้แค่ 30%)
- อาวุธติดตั้งต้องมีช่างกลดูแล มิฉะนั้นจะเสื่อมทุกคืนที่ใช้งาน

### ความรู้สึกตอนยิง (ส่วนแบบ Boxhead)

คอมโบฆ่าต่อเนื่อง (kill chain) ให้คะแนน คะแนนแปลงเป็น influence หลังคืนฝูงบุก · hit-stop สั้น · ซอมบี้กระเด็นตามทิศกระสุน · ตกน้ำมีสาดน้ำ · กระสุนเจาะหลายตัวเห็นเป็นเส้น tracer

**ผลเมื่อโดนยิงและตาย** (ทุกค่าอยู่ใน data ต่อชนิดศัตรู):

- **ช้าลงเมื่อโดนยิง:** ศัตรูที่ไม่มีเกราะช้าลงชั่วครู่ทุกครั้งที่โดนกระสุน (ค่าเบื้องต้น −30% นาน 0.4 วินาที ซ้อนได้ไม่เกินเพดาน) พร้อมท่าสะดุ้ง ตัวหุ้มเกราะและยักษ์ไม่ช้าลง
- **เลือด:** กระเด็นตามทิศกระสุนเป็น particle สั้นๆ และทิ้งรอยบนพื้นและผนังเป็นแผ่นแบนสีเรียบ บนน้ำเป็นคราบที่จางเร็ว เลือดซอมบี้สีคล้ำต่างจากเลือดคน รอยเลือดมีเพดานจำนวน รอยเก่าสุดหายก่อน
- **ศพ:** ตายแล้วเล่นท่าล้ม แล้วทิ้งศพไว้ในท่านั้น จำนวนศพมีเพดาน ศพเก่าจางหาย ศพที่ตกน้ำลอยสักพักแล้วจม
- **Ragdoll แบบปลอม (J, 2026-10-27):** ไม่ใช้ ragdoll physics กับฝูง (ฝูงเป็น MultiMesh + VAT ไม่มี skeleton) โดนระเบิดหรือแรงปะทะสูงจะเล่นท่าตาย "กระเด็น" และเลื่อนศพเป็นวิถีโค้งตามทิศแรงจนตกพื้นหรือตกน้ำ ragdoll จริงพิจารณาเฉพาะศัตรูมนุษย์ (ตัวน้อย) ใน preset High บน desktop ภายหลัง
- **ชิ้นส่วนขาด:** ตอนตายมีโอกาสสุ่มให้แขน ขา หรือหัวขาด (ลูกซองและระเบิดมีโอกาสสูงกว่า) ชิ้นส่วนกระเด็นตามทิศแรงปะทะเป็น rigid body จริงแต่มีเพดานพร้อมกัน (เริ่มต้น 16 ชิ้น เก่าสุดหยุดและกลายเป็นชิ้นนิ่ง) ศพที่เหลือเป็นแบบที่ขาดส่วนนั้น
- **สไตล์:** low-poly สีเรียบตามสไตล์ 1.5 ไม่ใช่ gore สมจริง ต้องไม่บังการอ่านสนาม
- **ตั้งค่า "เลือดและชิ้นส่วน" เปิด/ปิด** (ค่าเริ่มต้นเปิด) สำหรับเรตเนื้อหาและการสตรีม

**เอฟเฟกต์ระเบิดและไฟ** (วัดงบใน spike 0.7):

- **ระเบิด:** แสงวาบ 1 ดวงสั้นๆ · particle เศษและควัน · รอยไหม้บนพื้น · โดนน้ำเป็นเสาน้ำ · แรงผลักศพ ชิ้นส่วน และ prop · พังชิ้นส่วนที่ทำลายได้ (หัวข้อ 10)
- **ไฟติดตัว:** สถานะต่อตัว ดาเมจต่อวินาทีตามแหล่งไฟ ทำเป็น flag ต่อ instance ใน shader ของฝูง (เรืองแสงสั่นไหว) + particle เล็กน้อยที่ใช้ร่วมกัน ไม่มี particle node ต่อซอมบี้ ตัวที่ติดไฟวิ่งไปชนตัวอื่นทำให้ไฟลามได้ กระโดดน้ำ = ดับ
- **ไฟติดพื้น:** เป็นค่าต่อ cell ใน NavGrid มีอายุ ให้ flow field เห็นเป็นต้นทุนสูง (ซอมบี้เฉื่อยอ้อม ตัวไล่ล่าฝ่า) ฝนและปืนฉีดน้ำดับได้ ลามไปโครงสร้างไม้ของฐานได้ บนน้ำไม่ติด ยกเว้นคราบน้ำมัน

## 7. ชุดและอุปกรณ์

ชุดมีสองชั้นแยกกัน: **ฟังก์ชัน** (ป้องกันอะไร แลกกับอะไร) และ **หน้าตา** (ทรง สี ลาย) ทำให้เกมมีชุดได้หลากหลายมากโดยไม่ทำให้สมดุลเกมซับซ้อน

**ช่องสวมใส่ 7 ช่อง:** ศีรษะ · ใบหน้า · ลำตัวชั้นนอก · ลำตัวชั้นใน/เกราะ · ขา · เท้า · เป้

| ชุดพิเศษ | ช่อง | ป้องกัน / ปลดล็อก | แลกกับ |
| --- | --- | --- | --- |
| ชุดดำน้ำลึก (หมวกทองเหลือง) | ศีรษะ + ลำตัว + ขา | ลงชั้นน้ำท่วมได้นาน กันกัดใต้น้ำ | บนบกเดินช้ามาก มองเห็นแคบ ใส่เกราะไม่ได้ |
| ชุดดำน้ำเบา (หน้ากาก + ถัง) | ใบหน้า + เป้ | ดำน้ำตื้นสั้นๆ | เสียช่องเป้ |
| เสื้อกันฝน / ปอนโช | ลำตัวชั้นนอก | กันป่วยจากฝน | ร้อนจัด → หิวน้ำเร็วขึ้น |
| หน้ากากกรอง | ใบหน้า | เข้าโซนสปอร์/รัง แก๊สพิษ | ไส้กรองหมดอายุ สแตมินาฟื้นช้า |
| บูตยางกันไฟรั่ว | เท้า | กันไฟช็อตในน้ำ (รวมที่ช็อตไฟฟ้าของเรือตัวเอง) | เดินเสียงดังขึ้น |
| ชุดเอี๊ยมยาง (waders) | ขา | เดินน้ำท่วมอกได้เร็ว ไม่ป่วยจากน้ำสกปรก | ตกน้ำลึก = น้ำเข้าชุด จมเร็ว |
| เกราะกันมีด / กันกัด | เกราะ | ลดโอกาสถูกกัด = ลดโอกาสติดเชื้อ | หนักเล็กน้อย |
| เกราะกันกระสุน | เกราะ | กันกระสุนเจาะต่ำ (ศัตรูมนุษย์) | สแตมินา − ว่ายน้ำช้า |
| เกราะหนัก | เกราะ + ศีรษะ | กันทุกอย่างระดับสูง | **ตกน้ำ = จมทันที** วิ่งไม่ได้ เสียงดัง |

การแลกเปลี่ยนที่สำคัญที่สุดคือ **น้ำหนักกับน้ำ**: เกราะยิ่งหนัก ยิ่งอันตรายบนสะพานและบนเรือ ผู้เล่นต้องจัดชุดตามภารกิจ ไม่มีชุดที่ดีที่สุดสำหรับทุกสถานการณ์

**ความหลากหลายของหน้าตา (ระบบ modular):**

- **ทรง:** แต่ละช่องมีหลายทรง เช่น ลำตัวชั้นนอก: แจ็กเก็ตสนาม ฮู้ด เสื้อกั๊ก เสื้อชูชีพ ชุดช่าง เสื้อกาวน์แพทย์
- **สี:** palette จำกัด \~24 สีที่เข้ากันทั้งเกม (กันหน้าตาเกมเลอะ) ย้อมใหม่ได้ที่ห้องตัดเย็บ
- **ลาย:** พื้น ลายทาง ลายพราง ลายสก็อต ลายดอก แถบสะท้อนแสง — ทำเป็น shader mask ไม่ต้องมี texture แยก
- **สภาพ:** ใหม่ → เก่า → ขาด (ความทนทานของชุดแสดงผลบนตัวละคร) และเปียก/แห้ง
- **ความเป็นกลุ่ม:** เลือกสีประจำชุมชน (ผ้าพันแขน ป้าย ธงบนฐาน) ช่วยแยกพวกจากศัตรูมนุษย์ได้ทันที

ผู้รอดที่ไม่ได้ควบคุมเปลี่ยนชุดเองตามสถานการณ์ได้ (ใส่เสื้อกันฝนตอนฝนตก ถอดเกราะตอนนอน) ซึ่งเพิ่มความมีชีวิตให้ฐาน

## 8. เรือ

เรือคือยานพาหนะหลักและฐานเคลื่อนที่ มีตัวเรือ 1 แบบแต่ละขนาด และมีช่องอัปเกรดตามขนาด อัปเกรดทุกชิ้น**เห็นบนตัวเรือ**

| ตัวเรือ | คน | ช่องอัปเกรด | ความจุของ |
| --- | --- | --- | --- |
| แพถังลอย | 1 | 1 | 4 |
| เรือพาย | 2 | 2 | 8 |
| เรือหางยาว / เรืออลูมิเนียม | 3 | 3 | 16 |
| เรือบรรทุก (ปลายเกม) | 4 | 4 | 30 |

**การขับเคลื่อน (เลือก 1 ช่อง):**

| ขับเคลื่อน | ความเร็ว | ใช้ | เสียง |
| --- | --- | --- | --- |
| พาย | ช้า | สแตมินาของคนพาย (พาย 2 คนเร็วขึ้น) | เงียบมาก |
| ใบเรือ | กลาง (ขึ้นกับทิศลม) | ไม่ใช้อะไร พายุ = ใบขาด | เงียบ |
| เครื่องยนต์หางยาว / ใบพัด | เร็วสุด | น้ำมัน ใบพัดติดเศษขยะได้ | ดัง (ดึงดูดซอมบี้ในน้ำ) |

**ช่องอัปเกรด:** กล่องเก็บของ (+ความจุ) · ปืนพ่นไฟหัวเรือ · ปืนฉีดน้ำแรงดันสูง (ผลักซอมบี้ที่เกาะเรือออก) · **ที่ช็อตไฟฟ้าลงน้ำ** (ดาเมจทุกตัวในน้ำรอบเรือ รวมผู้รอดที่ไม่ได้ใส่บูตกันไฟรั่ว) · สปอตไลท์ · เกราะกันกระแทก · เตียงพยาบาลสนาม

**ความเสียหาย:** ตัวเรือมี HP ถูกซอมบี้เกาะ ชนเศษซาก หรือถูกยิง ต่ำกว่า 30% เริ่มมีน้ำเข้า ต้องมีคนวิดน้ำ เรือจม = ของหาย คนต้องว่ายน้ำ (เกราะหนัก = จม) เรือที่จมกู้คืนได้ด้วยการดำน้ำ

**เรือในคืนฝูงบุก:** เรือที่จอดที่ท่าเป็นทั้งเป้าหมายที่ซอมบี้พัง และป้อมปืนที่ติดอาวุธได้ ทำให้ผู้เล่นต้องตัดสินใจว่าจะป้องกันหรือยอมเสียเรือ

## 9. ศัตรู

ศัตรูทุกชนิดมี silhouette และสีที่แยกออกทันที และมีอาวุธที่แก้ทางอย่างน้อยหนึ่งชนิด ทำให้การเลือกอาวุธและกระสุนก่อนออกสำรวจมีความหมาย

**ความหลากหลายภายในชนิด:** ซอมบี้แต่ละชนิดมีแบบย่อยหลายแบบ เพื่อไม่ให้ฝูงดูเป็นตัวเดียวกันซ้ำๆ

- ชาย / หญิง × รูปร่าง และเศษเสื้อผ้าตามที่มา (ชาวบ้าน คนงาน หมอ ตำรวจ ทหาร → หุ้มเกราะ) รวมถึงโทนผิวเขียวซีดและผมต่างกัน
- **silhouette ของชนิดต้องเด่นกว่าแบบย่อยเสมอ:** แบบย่อยเปลี่ยนรายละเอียด ไม่เปลี่ยนรูปทรงหลักที่ใช้บอกชนิด
- เทคนิค: mesh ไม่กี่แบบต่อชนิด (แบบละ 1 MultiMesh) และสีต่อตัวผ่าน instance color เดโมเว็บ: Walker อย่างน้อย 4 แบบย่อย

### ซอมบี้

| ชนิด | พฤติกรรม | จุดแข็ง | จุดอ่อน / แก้ด้วย |
| --- | --- | --- | --- |
| เดินเซ (Walker) | เดินตามเสียง มาเป็นฝูง | จำนวน | ทุกอาวุธ กระสุนเจาะทะลุแถว |
| บวมน้ำ (Bloater) | ช้า ตายแล้วระเบิดก๊าซพิษ | ทำให้พื้นที่ติดเชื้อ | ยิงจากระยะไกล หน้ากาก ไฟเผาก๊าซ |
| นักว่าย (Swimmer) | ซ่อนใต้น้ำ พุ่งขึ้นเกาะเรือ/ดึงคนลงน้ำ | มองไม่เห็น | ช็อตไฟฟ้าเรือ ปืนยิงใต้น้ำ บนบกอ่อนแอ |
| นักวิ่ง (Runner) | เร็ว ไล่ตามระยะสั้น | ความเร็ว | HP ต่ำ ลูกซอง ปืนฉีดน้ำผลักตก |
| หุ้มเกราะ (Armored) | อดีตทหาร/ตำรวจใส่เกราะ | กันกระสุนเจาะต่ำ | กระสุน AP ไฟ หัว (หมวกหลุดได้) |
| ผู้ส่งเสียง (Screamer) | เห็นคนแล้วกรีดเรียกฝูง | เปลี่ยนการสู้เล็กเป็นฝูง | ฆ่าเงียบก่อนถูกเห็น (หน้าไม้ มีด) ระเบิดแสง |
| ยักษ์ (Juggernaut) | พังแนวกั้น ไม่กลัวการผลัก | HP สูงมาก | ระเบิด ปืนครก ล่อให้ตกน้ำลึก |
| ตัวเกาะ (Crawler) | เกาะผนังตึก ปีนขึ้นหลังคาได้ทุกด้าน | หลบแนวกั้น | ปืนฉีดน้ำพ่นให้หลุดตก สปอตไลท์ |
| รัง (Nest / Heart) | ไม่เคลื่อนที่ อยู่ชั้นจมน้ำ เกิดซอมบี้เรื่อยๆ | ขยายสปอร์รอบๆ | ไฟ ระเบิด ต้องใส่หน้ากาก |

**HP เริ่มต้น (ใช้คู่กับตารางปืนในหัวข้อ 6):** Screamer 50 · Runner 60 · Walker 100 · Crawler 80 · Swimmer 90 · Armored 150 + เกราะ M · Bloater 250 · Juggernaut 1500 + เกราะ H · Nest 3000 (ดาเมจไฟ ×2)

**การรับรู้:** ซอมบี้ใช้เสียงเป็นหลัก ตาเป็นรอง (ระยะมองลดในหมอกและกลางคืน) มี 3 สถานะ: เฉื่อย → สงสัย (เดินไปที่เสียง) → ไล่ล่า ฝูงใหญ่ใช้ flow field ร่วมกัน ไม่ใช่ pathfinding รายตัว

### ศัตรูมนุษย์

| กลุ่ม | พฤติกรรม | เจอที่ไหน |
| --- | --- | --- |
| โจรสลัดน้ำ (Raiders) | ตั้งด่านเก็บค่าผ่านทาง ปล้นเรือ บุกฐาน | ทางน้ำหลัก ตึกสูง |
| ผู้คลั่งศาสนาน้ำ (Cult) | บูชาน้ำท่วม ปล่อยซอมบี้ใส่ฐานคนอื่น ใช้ก๊าซ | ย่านจมลึก ใกล้รัง |
| อดีตทหารกำลังควบคุม (Remnant) | อาวุธดี เกราะหนัก คุมทรัพยากรใหญ่ เจรจาได้ | โรงพยาบาล ศูนย์ราชการ |
| กลุ่มที่กลายเป็นศัตรู | enclave ที่ความสัมพันธ์ตกต่ำกว่าเกณฑ์ | ทุกที่ |

ศัตรูมนุษย์ใช้ AI คนละแบบกับซอมบี้: หาที่กำบัง อ้อม ถอยเมื่อเจ็บ ยอมแพ้ การยิงใส่คนดึงดูดซอมบี้เข้ามา ทำให้การสู้สามฝ่ายเกิดขึ้นเอง ศัตรูมนุษย์ปรากฏตั้งแต่ Early Access เดโมเว็บมีเฉพาะซอมบี้

**หน้าตาศัตรูมนุษย์:** ใช้ระบบตัวละครเดียวกับผู้รอด (ร่างชาย/หญิง สีผิว ผม ชุด modular) แยกกลุ่มด้วยสีประจำกลุ่มและเครื่องแบบหรือสัญลักษณ์ (โจรสลัด: ผ้าโพกและเสื้อชูชีพสีแดง · ลัทธิ: ผ้าคลุมสีน้ำ · Remnant: ชุดพรางและเกราะ) ผลเมื่อโดนยิงและตายใช้กฎเดียวกับหัวข้อ 6 รวมถึงชิ้นส่วนขาด

## 10. โลก ภัยคุกคาม และกลุ่มผู้รอดอื่น

แผนที่เมืองสร้างแบบ procedural จาก seed ทุกรอบเล่น แบ่งเป็นย่านที่มีเอกลักษณ์ ตึกสร้างจาก modular kit ตามกฎของย่าน

| ย่าน | ของที่มีมาก | ความเสี่ยง | ลักษณะตึก |
| --- | --- | --- | --- |
| ที่อยู่อาศัย | อาหาร เสื้อผ้า หนังสือ | ต่ำ | ตึกแถว คอนโด 3–6 ชั้น |
| ย่านการค้า | อาหารกระป๋อง วัสดุ เครื่องมือ | กลาง | ห้าง ตลาด ตึกกว้างเตี้ย |
| โรงพยาบาล | ยา อุปกรณ์การแพทย์ | สูง (สปอร์) | อาคารสูง โซนกักกัน |
| ท่าเรือ / อุตสาหกรรม | น้ำมัน ชิ้นส่วน เรือ | กลาง–สูง (โจรสลัด) | โกดัง ปั้นจั่น คอนเทนเนอร์ |
| ศูนย์ราชการ | อาวุธ กระสุน เกราะ | สูง (อดีตทหาร) | สถานีตำรวจ ค่าย ศาลากลาง |
| ย่านจมลึก | ของหายากทุกชนิด | สูงมาก (รัง ผู้คลั่งศาสนา) | เห็นแค่ยอดตึก ต้องดำน้ำ |

**ระดับน้ำตามฤดู:** 3 ฤดู วนเป็นรอบ 21 วันในเกม (ปรับได้) รายละเอียดจาก J (2026-10-27): น้ำ**ไม่เคยลดถึงถนน** ระดับต่ำกับระดับสูงต่างกันแค่ 1 ชั้น

| ฤดู | ระดับน้ำ | ผล |
| --- | --- | --- |
| ฤดูน้ำลด | ลดลง 1 ชั้นในช่วงต้นฤดู | ชั้นที่โผล่ขึ้นมาเดินและค้นได้ (โคลน เศษซาก ของที่ยังไม่มีใครค้น) เดินบนหลังคาต่ำได้ |
| ฤดูร้อน | ต่ำ (คงที่) | ชั้นนั้นยังเปิดอยู่ น้ำนิ่ง น้ำดื่มขาดแคลน โรคระบาดในน้ำสกปรก |
| ฤดูฝน | ขึ้นกลับ 1 ชั้นทีละนิด | ชั้นนั้นท่วมคืน ของที่ไม่ได้ขนออกจมไปด้วย พายุบ่อย สะพานต่ำจม ชั้นที่ฐานยึดไว้ต้องสูบน้ำตลอดหรือปิดช่องเปิดถาวร (หัวข้อ 4) |

น้ำขึ้นและลงทีละน้อย (มีเตือนผ่านวิทยุ) ไม่ใช่ทันที เทคนิค: ระดับน้ำเป็นค่าเดียวทั้งแผนที่ (uniform `water_level` ที่มีอยู่แล้ว) อยู่ระหว่างสองระดับที่ห่างกัน 1 ชั้น (3.2 m) NavGrid ของชั้นนั้นคำนวณใหม่เฉพาะตอนที่น้ำข้ามระดับพื้นชั้น

**ขนาดแผนที่ (สองชั้น):**

- **ระดับเมือง:** 6 ย่าน ย่านละ 12–20 ตึก จำลองแบบหยาบใน SimCore (ค่าภัย ของที่เหลือ ผู้ครอบครอง) ไม่จำลองซอมบี้รายตัว
- **พื้นที่เล่นจริง:** โหลดทีละบล็อก ประมาณ 120 × 120 m (4–8 ตึก) เดินทางข้ามบล็อกด้วยเรือ ฉากตอนนี้ใช้ ~59 draw calls ต่อบล็อก เมืองต่อเนื่องทั้งเมืองจะเกินงบ 250 และขนาดดาวน์โหลด 50 MB
- **เดโม:** 1 บล็อก 4–6 ตึก

**ผู้ครอบครองตึก (`occupant`):** ค่าเดียวใน SimCore กำหนดทั้งหน้าตา (kit ใช้เป็น parameter แบบเดียวกับ `decay` และหน้าต่างมีไฟ) และ gameplay

| occupant | หน้าตา | gameplay |
| --- | --- | --- |
| รัง (nest) | สปอร์ เถาวัลย์หนา หน้าต่างดำ | เกิดซอมบี้เรื่อยๆ ค่าภัยย่านขึ้น |
| ร้างมีซอมบี้ (infested) | decay สูง | ค้นของ เสี่ยงปานกลาง |
| ศัตรูมนุษย์ตามกลุ่ม | ธง แนวกั้น สีประจำกลุ่ม (หัวข้อ 9) | ด่าน ปล้น เจรจา |
| enclave ที่เป็นมิตร | หน้าต่างมีไฟ ผ้าตาก สวนบนหลังคา | ค้าขาย ภารกิจ รับคนเข้าฐาน |
| ชุมชนแพลอยน้ำ | แพหลายลำผูกต่อกันกลางน้ำ | ตลาดน้ำ (เชื่อมกับผู้นำแบบ Trader หัวข้อ 12) |

**จุดของดี:** จุดฮอตบนยอดตึก กล่องทหาร กล่องแพทย์ เป็นจุด loot ระดับสูงประจำตึก มักมีผู้เฝ้า **Airdrop** เป็นเหตุการณ์ของเมือง ประกาศผ่านวิทยุ ใครถึงก่อนได้ก่อน จุดดรอปส่งเสียงดึงฝูงและศัตรูมนุษย์ (เสาหลักที่ 3)

**การทำลายสภาพแวดล้อม (3 ระดับ ไม่ใช้ physics fracture เพราะเว็บเป็น single-thread):**

1. **ชิ้นเล็ก:** แนวกั้น ประตู ไม้ตีหน้าต่าง ลัง มีสภาพ ดี → เสียหาย → พัง สลับ mesh และอัปเดต NavGrid ทันที ทางเดินของฝูงและแนวกระสุนเปลี่ยนตาม
2. **ที่กำบัง:** กระสอบทราย ไม้ อิฐ มี HP และระดับวัสดุสำหรับการเจาะ (หัวข้อ 6)
3. **ตึก:** เฉพาะจุดอ่อนที่ออกแบบไว้ (เช่นมุมถล่มและหลุมหลังคาของ kit ตึก) ระเบิดหรือปืนครกเปลี่ยนเป็นแบบพังพร้อมเศษซาก บางจุดเปิดทางใหม่หรือกลายเป็นสะพานข้ามน้ำ

**ดรอปและการหาของ:**

- **ตู้และจุดค้น:** loot table ตามชนิดตู้ × ผู้ครอบครอง × ย่าน
- **ศัตรู:** ศัตรูมนุษย์ทิ้งอาวุธที่ถือ (ความทนทาน 20–60%) และกระสุน ซอมบี้ดรอปน้อยตามที่มาของแบบย่อย (ซอมบี้ตำรวจ: กระสุน .45 · ซอมบี้ทหาร: 5.56 · ซอมบี้หมอ: ยา)
- **ฟาร์มของ:** ตึกที่ค้นแล้วหมดไป ไม่มี respawn เพื่อกันการวนฟาร์มซ้ำ แหล่งที่ได้ของซ้ำ: เกษตร ตกปลา พ่อค้า airdrop outpost และ**ฤดูน้ำลดเปิดชั้นที่ยังไม่มีใครค้น**

**ระบบเควส (4 ชั้น สร้างจาก template):** เป้าหมายผู้นำ (หัวข้อ 12) · สายภารกิจของ enclave · ภารกิจตามสถานการณ์ (ด้านล่าง) · **เควสส่วนตัวของผู้รอด** (ตามหาครอบครัว กลับไปบ้านเก่า แก้แค้นกลุ่มที่ฆ่าเพื่อน) เดโมมี 3–4 template

**รังและระดับภัยคุกคาม:** ทุกย่านมีค่าภัย 0–100 เพิ่มขึ้นทุกวันจากรังในย่าน เกิน 50 เกิดซอมบี้พิเศษ เกิน 80 ส่งฝูงเดินทางไปที่ฐานที่ใกล้ที่สุด ทำลายรังลดค่าภัยทันที

**คืนฝูงบุก:** โอกาสเกิดขึ้นกับ **เสียงสะสมของฐาน** (เครื่องปั่นไฟ โรงงาน การยิงจากหอคอย คนนอนกรน) และค่าภัยย่านรอบๆ เตือนล่วงหน้า 1 วัน (ห้องวิทยุเตือนได้ 2 วัน) ฝูงเข้ามาหลายทาง: สะพาน บันได ท่าเรือ ผนังตึก ผู้เล่นควบคุมคนหนึ่ง คนอื่นประจำหอคอยและซ่อมแนวกั้นเอง จบเมื่อกำจัดครบหรือถึงรุ่งเช้า

**Outposts:** ยึดตึกที่ค้นหมดแล้วด้วย influence ได้โบนัสตามชนิดตึก (ตึกสูง = เห็นแผนที่ไกล · โรงพยาบาล = ยาต่อวัน · ปั๊มน้ำมัน = น้ำมัน) ติดตั้งปืนครกและจุดจอดเรือได้ แต่ถูกบุกแยกได้ถ้าค่าภัยย่านสูง

**กลุ่มผู้รอดอื่น (Enclaves):** มีค่าความสัมพันธ์ ศัตรู → เป็นกลาง → มิตร → พันธมิตร พันธมิตรให้โบนัสถาวร (ส่งคนมาช่วยคืนฝูงบุก ค้าขายราคาดี) หรือเชิญเข้ามาอยู่ในฐานทั้งกลุ่ม

**ภารกิจตามสถานการณ์ (หมดเวลาได้):** เกิดจาก template ผสมกับสถานะโลก เช่น enclave ขอยา · สัญญาณวิทยุขอความช่วยเหลือ · สมาชิกหายตัวในพายุ · ผู้รอดติดอยู่บนหลังคาที่น้ำกำลังขึ้น · พ่อค้าเร่เรือมาถึง · สมาชิกอยากกลับไปดูบ้านเก่า ตัดสินใจไม่ทัน = ผลเสียต่อขวัญหรือความสัมพันธ์

## 11. ทรัพยากรและเศรษฐกิจ

ฐานใช้ทรัพยากรตอนเช้าทุกวัน ขาดตัวไหนก็ตาม ขวัญชุมชนลดทันที ค่าด้านล่างเป็นค่าเริ่มต้นสำหรับปรับสมดุล ไม่ใช่ค่าสุดท้าย

| ทรัพยากร | ใช้ต่อวัน (เริ่มต้น) | ได้จาก | ขาดแล้ว |
| --- | --- | --- | --- |
| อาหาร | 1 / คน | ค้น เกษตร ตกปลา ค้า | หิว → สแตมินา − → ป่วย |
| น้ำสะอาด | 1.5 / คน (×1.5 ตอนร้อนจัด) | ถังน้ำฝน กรองน้ำ ค้น | กระหาย → ดื่มน้ำท่วม = ป่วย |
| ยา | ตามเหตุการณ์ | ค้น ห้องพยาบาล สมุนไพร | บาดเจ็บหายช้า ติดเชื้อรักษาไม่ได้ |
| วัสดุ | 1 + ค่าซ่อม | ค้น รื้อถอนเศษซาก | สิ่งก่อสร้างเสื่อม |
| น้ำมัน | ตามเครื่องปั่นไฟและเรือ | ค้น ปั๊มน้ำมัน outpost | ไฟดับ เรือยนต์ใช้ไม่ได้ |
| กระสุน | ตามการยิง | ค้น คลังอาวุธ ค้า | หอคอยยิงไม่ได้ |
| ไฟฟ้า | ตามห้องที่เปิด (ไม่เก็บสะสมถ้าไม่มีแบต) | โซลาร์ เครื่องปั่นไฟ กังหันลม | ห้องที่ต้องใช้ไฟหยุด |
| Influence | — | ภารกิจ ช่วย enclave คะแนนคืนฝูงบุก บริจาคของ | — |

**Influence** คือสกุลเงินทางสังคม ใช้รับสมาชิกใหม่ ยึด outpost ค้าขาย และขอความช่วยเหลือ เก็บได้ไม่จำกัดแต่ใช้หมดเร็ว

**สมดุลเป้าหมาย (ใช้ตอนทดสอบ):**

- ฐาน 3 คนที่ไม่ออกสำรวจเลย อยู่ได้ประมาณ 4 วันก่อนขาดแคลน
- ออกสำรวจ 1 ครั้งที่สำเร็จควรได้ของพอใช้ 1.5–2 วัน
- เกษตรและกรองน้ำระดับ 2 พอเลี้ยงคน 4 คนแบบพอดี ทำให้การออกสำรวจย้ายจากความจำเป็นไปเป็นการหาของหายาก
- ชุมชนที่ใหญ่เกินกำลังผลิตต้องรู้สึกได้เร็ว ทำให้การรับคนใหม่เป็นการตัดสินใจจริง

**การค้า:** พ่อค้าเร่มาตามรอบ 2–3 วัน และ enclave ที่เป็นมิตรค้าขายได้ตลอด ราคาขึ้นกับความขาดแคลนตามฤดู (น้ำดื่มแพงตอนร้อน น้ำมันแพงตอนฝน)

## 12. ความก้าวหน้าระยะยาว

เมื่อพลเมืองดีเด่นคนแรกเกิดขึ้น ผู้เล่นแต่งตั้งเป็นผู้นำได้ บุคลิกผู้นำกำหนดห้องพิเศษและเป้าหมายปิดเกมของชุมชนนั้น

| ผู้นำ | ห้องพิเศษ | เป้าหมายปิดเกม |
| --- | --- | --- |
| นักรบ (Warlord) | ค่ายฝึก (ทักษะต่อสู้เร็วขึ้น) | ทำลายรังทั้งหมดในเมือง |
| ผู้พิทักษ์ (Sheriff) | หอสัญญาณ (เตือนภัยล่วงหน้า) | ส่งสัญญาณเรียกการอพยพคนทั้งเมือง |
| นักสร้าง (Builder) | อู่ต่อเรือใหญ่ | สร้างเรือพาทุกคนออกจากเมือง |
| พ่อค้า (Trader) | ตลาดน้ำ | สร้างเครือข่าย enclave เป็นพันธมิตรทั้งเมือง |

**Legacy:** เมื่อชุมชนบรรลุเป้าหมายหรือล่มสลาย (ทุกคนตายหรือหนี) เกมจบรอบนั้น เลือกผู้รอดที่ยังมีชีวิตได้ 1–3 คนไปเริ่มเมืองใหม่ (seed ใหม่) พร้อมรางวัลถาวรตามเป้าหมายที่ทำได้ เช่น เริ่มด้วยปืนครก เริ่มด้วยเรือใหญ่ หรือเริ่มด้วย enclave มิตร

**การปลดล็อกข้ามรอบ:** blueprint อาวุธ ชุด และหน้าตาตกแต่งที่เคยเจอ ถูกเก็บไว้ใน "สมุดบันทึกผู้รอด" แต่ไม่ให้ของตั้งต้นที่ทำให้เกมง่ายเกินไป ความก้าวหน้าเพิ่ม *ตัวเลือก* ไม่ใช่พลังดิบ

**ความยาก:** เลือกตอนเริ่มเมือง (ความถี่คืนฝูงบุก ความหนาแน่นซอมบี้ ความขาดแคลน) แต่ตายถาวรทุกระดับ ไม่มีโหมดชุบชีวิต เกมบันทึกอัตโนมัติตอนเริ่มวันใหม่เท่านั้น (ไม่มี save scum)

## 13. Art direction และเสียง

ใช้ **สไตล์ 1.5**: รูปทรง low-poly สีเรียบที่อ่านง่าย บวกบรรยากาศจากแสง เงา และคราบน้ำ ทุกอย่างต้องทำได้บน WebGL2 อ้างอิงจากภาพจำลองคืนฝูงบุกที่ทำไว้

- **แยกด้วยอุณหภูมิสี:** ผู้รอด = สีอุ่นสด · ซอมบี้ = ผิวเขียวซีด เสื้อเทาเย็น · ศัตรูมนุษย์ = สีประจำกลุ่มที่ชัด · ของเก็บได้ = ขอบเรืองแสง · อันตราย = ส้ม/แดง
- **ตัวละคร:** สัดส่วนสมจริงขึ้น (หัว 1:6) แต่ยังเป็น low-poly มีแขนขาครบ ทุกตัวละครที่เป็นคน (ผู้รอดและศัตรูมนุษย์) ใช้ **rig เดียวกัน** แต่มี body 2 แบบ (ชาย/หญิง) + blend shape รูปร่าง + scale กระดูกเพื่อปรับส่วนสูง ผมและหนวดเป็นชิ้น modular ในช่องศีรษะ สีผิวและสีผมเป็นค่าต่อตัวใน shader ใช้ร่วมกับชิ้นส่วนชุดแบบ modular (หัวข้อ 7)
- **แอนิเมชัน:** เคลื่อนไหวสมจริงจาก mocap (Mixamo ซึ่ง J ดาวน์โหลดเอง)
  - **ผู้รอดและศัตรูมนุษย์:** skeleton + AnimationTree แยกท่อนบน (เล็งหรือยิง) กับท่อนล่าง (เดิน 8 ทิศ) เพราะ twin-stick เดินกับเล็งคนละทิศได้
  - **ซอมบี้ในฝูง:** ใช้ **vertex animation texture (VAT)** ที่ bake จาก Blender ให้ MultiMesh เล่นท่าเดิน/ตี/สะดุ้ง/ล้ม ต่อตัวด้วย offset เวลาสุ่ม ไม่มี skeleton รายตัว
  - **งบ:** ซอมบี้ต่อตัวประมาณ ≤ 500 สามเหลี่ยม (ตัวเลขจริงมาจาก spike 0.7) ผู้รอดและศัตรูมนุษย์มีบนจอน้อยตัว จึงละเอียดได้ถึงประมาณ 3–5k สามเหลี่ยมต่อตัว (ใบหน้า มือ รายละเอียดชุด)
- **แสง:** พระอาทิตย์ 1 ดวงตามเวลา + baked lightmap ต่ออาคาร + emissive หน้าต่าง/ไฟฉาย/กองไฟ
- **น้ำ:** shader เดียวทั้งเกม (สีตามความลึก คลื่น normal 2 ชั้น ฟองรอบวัตถุจาก depth) และคราบเปียกบนผนังตามระดับน้ำปัจจุบัน (เปลี่ยนตามฤดูอัตโนมัติ)
- **สภาพอากาศ:** ฝน = particle + ผิวเปียก (ลด roughness) · หมอก = depth fog · ร้อนจัด = สีอุ่นจัด + heat haze เบาๆ · พายุ = ลมแกว่งผ้าใบ + ฟ้าแลบ
- **Asset pipeline:** สร้างจาก Blender Python script เก็บใน Git export .glb สุ่ม variation จาก parameter ได้

**ความ immersive (เลือกเฉพาะที่คุ้มงบเว็บ):**

- เดินทางจากฐานไปจุดสำรวจด้วยเรือที่มองเห็นได้ ไม่มีหน้า loading ระหว่างฐานกับบล็อกใกล้เคียง
- ข่าวสารและคำเตือนมาจากวิทยุในเกม (diegetic) ไม่ใช่ popup
- น้ำกระเพื่อมรอบตัวละครและเรือ รอยเท้าเปียกบนหลังคาที่จางไป
- ไฟจริงมีเฉพาะที่มีคนอยู่ เมืองที่เหลือมืดและเงียบ (mood รกร้าง)
- ผู้รอดทำกิจวัตรตามสภาพอากาศและเวลา (หัวข้อ 2, 4) เสียงฐานซ้อนชั้น

**เสียง (ไม่มีเสียงพากย์):**

- บทสนทนาเป็นกล่องข้อความ + เสียง "gibberish" สั้นๆ ตามอารมณ์ ทำให้แปลได้ง่ายทุกภาษา
- เสียงเป็นกลไกเกม จึงต้องชัดเจน: เสียงครางซอมบี้บอกทิศทาง เสียงกรีดของ Screamer ต้องจำได้ทันที
- เสียงฐานแบบซ้อนชั้นตามกิจกรรม (ค้อนตอก เครื่องปั่นไฟ คนคุยกันรอบกองไฟ) คือส่วนสำคัญของบรรยากาศ settlement
- ดนตรี ambient ช่วงกลางวัน เพลงเร็วตอนคืนฝูงบุก แหล่งที่มา: CC0 + อัดเสียง foley เอง หรือจ้างทำเพลงตอนเฟส Steam

## 14. เทคนิคและแพลตฟอร์ม

เป้าหมายหลักคือ **โค้ดชุดเดียวรันทั้งบนเว็บและ Steam** ต่างกันแค่ renderer preset และที่เก็บ save เพื่อให้การ "ดึงระบบไปทำเกมขาย" ไม่ต้องเขียนใหม่

| หัวข้อ | เดโมเว็บ | Steam |
| --- | --- | --- |
| Engine | Godot 4.x · GDScript | เดียวกัน + C++ GDExtension ส่วนที่หนัก |
| Renderer | Compatibility (WebGL2) single-thread | Forward+ (preset High: SSR, SDFGI, เงานุ่ม) |
| เก็บ save | IndexedDB (user://) | ไฟล์ในเครื่อง + Steam Cloud |
| Deploy | GitHub Actions → GitHub Pages + itch.io (butler) | Steamworks depot |
| เป้าประสิทธิภาพ | 60 FPS บน Intel Arc iGPU ใน Chrome | 60+ FPS บน Steam Deck |

**สถาปัตยกรรม (แยกการจำลองออกจากการแสดงผล):**

- **SimCore** — ข้อมูลและกฎล้วน ไม่อ้างอิง Node: ผู้รอด ฐาน เศรษฐกิจ โลก ภัยคุกคาม สภาพอากาศ ระดับน้ำ อัปเดตเป็น tick ต่อชั่วโมงในเกม เทสด้วย unit test ได้โดยไม่เปิดเกม
- **Data** — อาวุธ ชุด ห้อง ศัตรู trait ภารกิจ เก็บเป็น Resource/JSON ปรับสมดุลได้โดยไม่แก้โค้ด
- **Presentation** — scene ของ Godot อ่านสถานะจาก SimCore ผ่าน signal: กล้อง ตัวละคร animation น้ำ UI
- **Combat runtime** — ส่วนเรียลไทม์: MultiMesh ซอมบี้ flow field กระสุนแบบ raycast ส่งผลกลับไป SimCore (ใครตาย ใช้กระสุนเท่าไหร่)
- **Save** = serialize SimCore อย่างเดียว มี schema version เพื่อ migrate ข้ามเวอร์ชัน

**งบประสิทธิภาพเว็บ:** draw calls < 250 · สามเหลี่ยมบนจอ < 300k · ซอมบี้พร้อมกัน 200+ · texture atlas 2048² 1–2 ไฟล์ · ดาวน์โหลดครั้งแรก < 50 MB · ไฟ dynamic ≤ 4 ดวงต่อวัตถุ · ผู้รอดในฐาน ≤ 6 คน · ศพและรอยเลือดมีเพดานจำนวน (ค่าจริงจาก spike 0.7)

**หน้าจอหลัก (UI):** ทุกหน้าใช้จอยได้ ทุกข้อความผ่าน `tr()`

### ต้องทดสอบก่อนเขียนระบบจริง (เฟส 0)

1. **ซอมบี้บนเว็บ:** MultiMesh + flow field ผ่านเกณฑ์เมื่อ 200 ตัวได้ ≥ 50 FPS บน laptop Arc ใน Chrome (single-thread) ไม่ผ่าน → ลดเป็น 100 ตัวและปรับคืนฝูงบุกเป็นหลายระลอก
2. **ภาพสไตล์ 1.5 บน WebGL2:** น้ำ + baked light + เงา ในฉากฐานจริง เทียบกับภาพจำลอง
3. **การควบคุม twin-stick:** เมาส์ + จอย มุม isometric เล็งแม่นและรู้สึกดี
4. **Save บนเว็บ:** เก็บและโหลด SimCore ผ่าน IndexedDB ได้หลังปิดเบราว์เซอร์
5. **ฝูงมีแขนขาบนเว็บ:** ซอมบี้ 200 ตัวเล่น VAT + ศพเต็มเพดาน + เลือด + ระเบิดและไฟ ยังได้ ≥ 50 FPS บน Arc ไม่ผ่าน → ลดแบบย่อยและเพดานศพ หรือลดเป็น 100 ตัว
6. **สำรวจในอาคาร:** ตึก 3 ชั้น กล้องตัดฉาก NavGrid ต่อชั้น ซอมบี้ 30 ตัวในตึก ≥ 50 FPS บน Arc และ J อ่านฉากออกทุกมุมกล้อง ไม่ผ่าน → ซ่อนบล็อกข้างนอกตอนอยู่ในตึก ใช้ cutaway แบบง่าย

ทุกข้อใช้ GDScript เพราะ Godot ยัง export C# ไปเว็บไม่ได้อย่างเป็นทางการ ([Godot forum, เม.ย. 2026](https://forum.godotengine.org/t/is-there-an-update-on-exporting-c-projects-to-web/128821))
